# Calculadora RUP

Aplicacion de escritorio de calculadora desarrollada en Python con Tkinter.
Incluye operaciones de suma, resta, multiplicacion y division.

## Requisitos

- Python 3
- Tkinter (incluido en la mayoria de instalaciones de Python)

## Ejecutar

Desde la carpeta del proyecto:

```powershell
python main.py
```

## Ejecutar pruebas

```powershell
python -m unittest discover -s pruebas
```
