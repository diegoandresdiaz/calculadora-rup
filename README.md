# Calculadora RUP

Aplicación de escritorio de calculadora desarrollada en Python con Tkinter. Incluye operaciones de suma y multiplicación.

## Requisitos

- Python 3
- Tkinter (incluido en la mayoría de instalaciones de Python)

## Ejecutar

Desde la carpeta del proyecto:

```powershell
python main.py
```

## Ejecutar pruebas

```powershell
python -m unittest discover -s pruebas
```
